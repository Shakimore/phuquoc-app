ФУКУОК — приложение поездки (работает офлайн)

КАК ВЫЛОЖИТЬ (GitHub Pages, 5 минут)
1. github.com → New repository → имя, например: phuquoc-app → Public → Create.
2. На странице репозитория: Add file → Upload files → перетащить ВСЁ содержимое этой папки
   (index.html, app.js, app.css, data.js, sw.js, manifest.webmanifest, .nojekyll, папки icons и vendor) → Commit.
3. Settings → Pages → Branch: main, папка / (root) → Save.
4. Через 1–2 минуты сайт откроется по адресу https://ВАШ_ЛОГИН.github.io/phuquoc-app/
   Проще всего: Халел кладёт эту папку в свой репозиторий phuquoc как папку app —
   адрес будет https://khalel98.github.io/phuquoc/app/

СВОЙ ДОМЕН (по желанию): Settings → Pages → Custom domain: trip.shakim.kz,
у регистратора домена добавить запись CNAME: trip → ВАШ_ЛОГИН.github.io

НА ТЕЛЕФОНЕ (каждому из четверых, пока есть интернет)
iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».
Samsung: открыть в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
Открыть приложение, выбрать своё имя, один раз зайти в «Сканер» и разрешить камеру.
После этого всё работает без интернета.

ЧТО МЕНЯТЬ
data.js — рейсы, места в самолёте, события, места на острове, правила, контакты.
После правок поменяйте номер версии в sw.js (первая строка) и в app.js (VERSION) — тогда телефоны подтянут обновление.

ВАЖНО
Сайт открыт всем, у кого есть ссылка. Паспортов, номеров брони и посадочных в нём нет специально.
Посадочные каждый добавляет у себя: «Инфо» → «Документы на этом телефоне» — они хранятся только в телефоне.

ОБЩИЙ БЮДЖЕТ АЛИШЕРА И АИДЫ (Supabase, 5 минут)
1. supabase.com → New project (любой регион, например Singapore).
2. SQL Editor → вставить содержимое файла supabase.sql → Run.
3. Project Settings → API: скопировать Project URL и ключ anon public.
4. В data.js в самом низу вписать: window.SYNC = { url: 'https://xxxx.supabase.co', key: 'anon-ключ' };
   и загрузить data.js на GitHub заново.
5. На телефоне Алишера: Инфо → Общий бюджет → «Придумать код» → Сохранить. Отправить код Аиде.
6. На телефоне Аиды: вписать тот же код → Сохранить.
Семейный код в код сайта НЕ вписывать — он играет роль пароля.
Файл supabase.sql на GitHub можно не выкладывать.
